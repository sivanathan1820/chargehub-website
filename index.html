Security & Access

Locked down by design

Hierarchical RBAC with a self-healing permission tree — it is structurally impossible to lock yourself out of admin.

🔐

JWT + Session Control

HS256 tokens with jti blacklisting and a live user_sessions table. Token lifetime is a DB setting — shorten it and older tokens die retroactively. Argon2 password hashing, revoke-all on password change.

🌳

Hierarchical Permissions

~100 permissions across 10 menu groups. Effective access = role grants ∪ direct grants − explicit denials, enforced by PermissionChecker (AND) and AnyPermissionChecker (OR).

🛡️

Lockout Protection

The API refuses to delete the last Admin, strip rbac:* / user:* permissions, rename protected rules, or empty a role of its menu access.

🗂️

Soft Delete & Audit

UUID keys, timestamp/soft-delete mixins, partial unique indexes so deleted rows free their names, append-only meter status history.

🖼️

Hardened Uploads

Pillow pipeline: decode → sniff format → re-encode → resize → strip metadata → content-addressed filename. Non-root Docker user throughout.

⚡

Graceful Caching

Versioned Redis keys for profiles, RBAC trees, settings and branding — flushed on startup, with TTLs from DB settings. Redis down never means a 500.
